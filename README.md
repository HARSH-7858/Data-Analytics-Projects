## How to View the Dashboards and Files

### Power BI

1. Install [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
2. Download a `.pbix` file from [`dashboards/power-bi/`](dashboards/power-bi/).
3. Open it in Power BI Desktop and refresh the data only if the referenced data
   sources are available locally.

### Tableau

1. Install [Tableau Desktop](https://www.tableau.com/products/desktop) or use
   Tableau Public where the workbook format is supported.
2. Download the workbook from [`dashboards/tableau/`](dashboards/tableau/).
3. Open the file in Tableau and reconnect any local data sources if prompted.

### Excel

1. Download a workbook from [`workbooks/excel/`](workbooks/excel/).
2. Open it in Microsoft Excel or a compatible spreadsheet application.
3. If formulas or external links are present, update the source path as needed.

## Data Notes and Reproducibility

- The files in [`data/raw/`](data/raw/) are retained as source inputs where
  redistribution is permitted.
- Add cleaned and analysis-ready outputs to [`data/processed/`](data/processed/).
- Document data-source URLs, refresh dates, assumptions, and known limitations
  in the relevant project section.
- Do not upload confidential, personally identifiable, licensed, or restricted
  data. Replace it with an anonymized or synthetic dataset before publishing.
